Renders a ticket's recorded event transcript (<dataDir>/data/transcripts/<id>.jsonl): one header per run — flow, model, outcome, duration, tokens, and the error line for a failed attempt — then each turn's text and every tool call with a one-line result summary. --tools prints the full tool results, --thinking the model's reasoning, --width N sets the wrap column, and --json emits the raw frames. --chat <owner/repo|path> prints a repo's dashboard chat transcript instead of a ticket's — your messages, the agent's answers, its tool calls, and every parked draft — in the same layout. The dashboard opens the ticket view with enter on any running or recent queue row, following a running ticket live until the run ends. 

junco transcript add-tide-rounding-2026-08-30
junco transcript fix-tide-rounding.jsonl --tools --width 100
junco transcript --chat acme/reef-api
